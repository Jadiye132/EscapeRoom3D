# Lista de pruebas del juego

- [ ] MainScene abre sin errores.
- [ ] El jugador se mueve con WASD o las flechas.
- [ ] E genera el mensaje de interacción.
- [ ] O abre y cierra la puerta.
- [ ] Con Entered Code en 0, P indica código incorrecto.
- [ ] Con Entered Code en 1234, P resuelve el puzzle.
- [ ] La consola no muestra errores de compilación.
