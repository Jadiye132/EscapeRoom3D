# RECOVERY_TEST — Caso 18 (Ayelen Cori)

Archivo de prueba del laboratorio Git + Unity «EscapeRoom3D».

**Propósito:** generar un commit local identificable para practicar la recuperación mediante `git reflog` sin alterar código del juego.

**Mensaje requerido:** `test: recovery point`.

Este archivo servirá para verificar visualmente que el contenido reaparece cuando se recupera el commit.
